# Scripts PowerShell

Las capturas de la fase 09 muestran scripts para alta, cambio de departamento y baja de empleados, pero el ZIP no contenía sus archivos `.ps1` editables.

**No se inventan aquí scripts supuestamente ejecutados.** Cuando se faciliten los originales, se revisarán para: quitar credenciales y datos sensibles, parametrizar entradas, implementar gestión de errores y documentar cómo verificar sus efectos.

Los procedimientos de solo lectura de cada fase pueden reproducirse desde los archivos Markdown de `docs/`.
